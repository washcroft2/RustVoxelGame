VOXEL GAME TEST (Windows)

What this is: a set of small test programs that measure how the game's graphics and networking
code runs on your computer. Nothing is installed, and nothing is sent anywhere by the programs.
It takes about 10 minutes.

Steps

1. Right-click the zip file and choose "Extract All...", then click Extract.
   (Do not run it from inside the zip.)
2. Open the extracted folder and double-click "run.bat".
3. Windows may show a blue box saying "Windows protected your PC". Click "More info", then
   "Run anyway". This is normal: the programs are not signed, because this is a private project.
   You may get the same warning for the individual programs; give the same answer.
4. A black window opens and shows progress. Leave it open until it says "Done".
5. Send the file "voxel-report.txt" from that folder to whoever sent you this.

These steps have not been tried on your machine. If anything looks different, or something fails,
please take a screenshot or a photo of the screen and send that too. It is useful information.
