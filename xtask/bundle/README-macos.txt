VOXEL GAME TEST (Mac)

What this is: a set of small test programs that measure how the game's graphics and networking
code runs on your Mac. Nothing is installed, and nothing is sent anywhere by the programs.
It takes about 10 minutes.

Steps

1. Double-click the zip file to unzip it. A folder called "voxel-test" appears.
2. Open the folder. Do NOT double-click "run.command" yet: macOS will refuse it the first time.
   Instead, hold the Control key and click "run.command" (or right-click it), choose "Open", and
   then click "Open" in the box that appears.
3. If macOS still refuses, open System Settings, go to "Privacy & Security", scroll down, and
   click "Open Anyway" next to the message about run.command. Then try step 2 again.
4. A Terminal window opens and shows progress. Leave it open until it says "Done".
5. Send the file "voxel-report.txt" from that folder to whoever sent you this.

These steps have not been tried on your Mac. If anything looks different, or something fails,
please take a screenshot or a photo of the screen and send that too. It is useful information,
because how macOS reacts to these programs is part of what we are testing.
